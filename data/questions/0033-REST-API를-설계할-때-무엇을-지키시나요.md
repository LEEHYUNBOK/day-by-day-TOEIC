REST API를 설계할 때 무엇을 지키시나요?

## 참고 답안
**자원은 명사, 행위는 HTTP 메서드**로 표현하고 상태를 서버에 두지 않습니다. 상태 코드를 용도대로 쓰는 것도 포함입니다 — 잘못된 요청 400, 인증 401, 권한 403, 없음 404.
